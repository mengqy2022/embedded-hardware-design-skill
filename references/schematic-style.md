# 通用原理图排版规范

适用范围：原理图的组织、表达和审查。本文采用 [S01、S03、S04](sources.md) 的公开/开源实践并补充工作区排版建议；不规定芯片引脚连接、电容值或 PCB 物理距离。规则编号 SCH-xx 供项目检查记录引用。

## 1. 页面先表达功能

| 编号 | 采用方法 | 检查方法与边界 |
|---|---|---|
| SCH-01 | 首页给出系统框图、电源树、页面目录、板号及修订；小板可以合并在同一页 | 读者能找到供电、主控、接口、时钟、复位和调试入口；不要为小板强行拆页 |
| SCH-02 | 按功能和电压域分块；大项目按供电、主控、存储、接口等分页 | 每块有标题和简短用途，输入、输出及电源来源可追踪；依据 S01 的 Schematic Reading Tips |
| SCH-03 | 主要信号从左向右；电源通常在上，地通常在下 | 反馈、双向总线和特殊模拟拓扑可例外；真实连接和可读性优先 |
| SCH-04 | 相关器件放在一起，按功能对齐并留出注释空间 | 上拉靠近对应总线，反馈网络靠近对应功能引脚；图上距离不代表 PCB 距离 |
| SCH-05 | 关键电源域与分离的 IC 电源单元有清楚的归属 | 单独绘制去耦页时，标明 IC 位号、电源域、对应引脚/组和回查页；不能只有一排无归属电容 |

以下仅展示页面分区，不是电路连接图，也不表示实际电源拓扑：

```text
┌──────────────────── 页面标题 / 板号 / 修订 ────────────────────┐
│ 电源输入与保护          电源转换 / 使能 / 电源状态             │
│                                                             │
│ 输入接口 / 调理    →    主控或功能 IC    →    输出接口 / 驱动   │
│                         时钟 / 复位                          │
│                                                             │
│ 去耦归属 / 启动配置       调试与测试       设计依据 / 装配选项   │
└─────────────────────────────────────────────────────────────┘
```

不要为了填满页面而放大无关器件或拉长走线。需要不断缩放才能读图时，先重新分块或分页，再考虑加大纸张。

## 2. 统一视觉样式

以下数值是**工作区排版建议**，按最终导出纸张的实际尺寸检查；不是电气参数或特定 EDA 的默认设置。

| 项目 | 建议起点 | 调整方式 |
|---|---|---|
| 纸张 | 小模块 A4，较复杂页面 A3；整套工程尽量统一 | 不通过把全部内容缩得很小来硬塞一页 |
| 位号、数值、网络标签 | 高度约 2.0–2.5 mm；同类文字一致 | 工具按字号或其他单位设置时，以导出结果复核 |
| 块标题、关键注释 | 块标题约 3–4 mm；普通注释约 2.0–2.5 mm | 用字号和位置区分层级，避免只靠颜色传递含义 |
| 网格 | 使用与符号引脚网格兼容的主网格；细网格优先用于文字 | 不为对齐文字而把器件或导线端点移离连接网格 |
| 导线与框线 | 普通导线统一线型，图框和功能分隔弱于电气连接 | 分隔框不能看起来像网络；不要用导线粗细暗示 PCB 载流能力 |
| 对齐与留白 | 同一组电阻/电容等距，对齐位号和数值 | 留白以避免文本、引脚号、连接点重叠为准，不规定固定器件间距 |
| 颜色 | 普通内容使用稳定主题，重点用标题/文字标记 | 黑白打印仍能识别 DNI、警告、可选路径和极性 |

位号和数值应紧邻所属器件，且不遮盖符号、引脚号、导线、连接点或其他文字。器件旋转后，重新检查文字方向；不要把大量竖排和倒置文字留到交付阶段。

## 3. 连线必须一眼可核对

| 编号 | 规则 | 依据与检查 |
|---|---|---|
| SCH-06 | 普通导线优先水平/垂直，减少折返、跨越及长距离绕线 | 工作区排版建议；不改变模拟反馈等拓扑的表达含义 |
| SCH-07 | 分支优先用 T 形连接，并检查连接点；减少四向交叉连接 | S01 的连接符号说明、S03 的 Connections/Junctions；在 EDA 高亮网络确认 |
| SCH-08 | 跨线不连接时保持清晰；不能仅凭“看起来碰到了”判断连接 | 连接点、端点和网络表共同确认；嘉立创 EDA 的具体行为以当前版本为准 |
| SCH-09 | 近处关键拓扑保留可见连线；远处重复网络可用标签 | 电源反馈、晶振、保护器件顺序等不应全部藏在标签后面 |
| SCH-10 | 标签放在实际网络上；区分本页、跨页和全局作用域 | S03 说明 KiCad 各类标签的作用域；其他 EDA 不能直接照搬同名对象的语义 |
| SCH-11 | 总线/线束必须核对各成员及引脚映射 | 总线图形不是每根信号已经连接的证据；检查导出网络表 |
| SCH-12 | 刻意不连接的引脚按数据手册处理，并使用工具支持的 NC 标记 | S03 的 no-connection flag 只表达意图；不能用 NC 标记掩盖漏接的电源或必接引脚 |

绘制后逐条高亮关键网络：供电与地、复位、启动 strap、反馈、差分正负、连接器电源和外部信号。可见导线、标签、引脚名称与实际网络表必须一致。

## 4. 命名和注释要消除歧义

- **SCH-13，网络名**：同一工程保持一致。可采用 `PWR_3V3`、`MCU_RESET_N`、`USB0_D_P` / `USB0_D_N` 等形式；真正导入为差分对前，要按 EDA 的配对语法确认。`_N` 可能表示低有效或差分负端，结合功能前缀和引脚表消歧。
- **SCH-14，接口方向**：`TX`、`RX` 要注明相对于哪端，例如 `MCU_UART0_TX`，不要在连接器另一端凭名字再次交换。连接器表同时写脚号、信号、电压域、方向和对端。
- **SCH-15，值与字段**：位号、数值、封装及采购 MPN 各在对应字段中。单位和小数表达一致；电阻的 `4.7k`/`4k7`、电容的 `100nF` 等选一种工程习惯，避免 `M`/`m` 混用。
- **SCH-16，选装**：DNI/DNP 选用一种主标记，说明装配变体。跳线、0 Ω 选路和互斥电阻写清默认装配、允许组合和连接结果，并同步 BOM。
- **SCH-17，设计依据**：重要计算、允许输入范围、上拉依据、终端和阻容选值旁附简短注释；完整计算、器件文档版本和页码放在项目设计记录中。
- **SCH-18，符号与封装**：逻辑引脚排列可以服务阅读；物理引脚号、隐藏电源、门单元和封装焊盘映射必须按准确 MPN 核对。连接器按配合面/焊接面明确观察方向，防止镜像。

`AGND`、`DGND` 等名称不自动意味着 PCB 要割地；分区、隔离和连接方式属于电气设计，见 [PCB-G04](power-ground.md)。

## 5. 交付前的排版与电气检查

1. **SCH-19，整页检查**：查看每页导出 PDF，按最终纸张尺寸或实际打印确认文字可读、留白适当、没有裁切及图框外对象。检查黑白显示。
2. **SCH-20，局部检查**：放大确认接点、相邻引脚、极性、网名和标签端点；从外部连接器追踪到目标 IC，再从 IC 追踪回来。
3. **SCH-21，一致性**：检查 BOM、封装、装配变体和原理图同一修订。复制模块后核对位号、地址、片选、网络标签作用域和独立电源域。
4. **SCH-22，检查证据**：运行适用的 ERC，并记录工具版本、设计修订、规则、错误/警告及豁免理由。ERC 不验证文字排版，也不能替代模拟连接、选值和时序审查。

完成记录使用 [原理图检查模板](../assets/SCHEMATIC_REVIEW.md)。尚未执行的检查保持未勾选；不适用项单独写明原因。

## 6. 用户确认的排版要求

2026-10-25，用户指定手动整理的原理图为排版样本，下列 SCH-23～27 为可复用提炼。原始图页、快照和工程留在本地，不随公开包分发。后续编辑先参考目标项目当前手绘版本；不重放旧排版脚本。

| 编号 | 要求 | 验收方式 |
|---|---|---|
| SCH-23 | 以用户当前器件本体位置为起点，保持符号、引脚和连接端点一致；仅在任务允许的范围内调整布局 | 器件移动或旋转后核对引脚、导线端点及文字；不能出现本体与引脚分离 |
| SCH-24 | 器件、引脚文字、位号、数值、网络名和功能标题不相互遮挡；导线不穿越无关符号或文字 | 整页查看分区和留白，局部放大逐组检查相邻引脚文字；不靠无限缩小字体消除重叠 |
| SCH-25 | 同一段由可见导线连续连接的网络，只保留一个清楚的网名标注；合并同段重复名称 | 保留真实物理脚号及符号必要的引脚名称；分离绘制或跨页的网络片段分别保留必要标签，不把不同网络改成同名 |
| SCH-26 | 按功能分框，框线对齐，标题位置和字号层级一致；同类支路等距，器件及标注方向协调 | 按实际项目的按键、接口、电源、时钟、复位和 MCU 等功能分区；允许合理留白，不强行填满页面 |
| SCH-27 | 局部拓扑优先直接连线，远处信号用简洁短线和必要网名；不同网络不重合，不以无意义折返或交叉挤占空间 | 同网导线合并为明确分支，接点清楚；不同网交叉按 SCH-07/08 表达并尽量减少；电气 DRC 与排版视觉检查分别验收 |

这些是用户的视觉与表达要求。样本中的芯片选值、旧注释和接口定义须按各项目规格核对，不能因排版被采用就视为电气依据。
