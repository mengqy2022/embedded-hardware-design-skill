# 核验与交付证据

历史报告仅证明对应修订。先记录当前工程、图页/PCB 身份、文件版本或校验值；修改前保留源文件与锁定对象基线。用户暂停或手动接管后停止写入；恢复工作先重新读取、比较，不重放旧坐标/布线补丁。

## 阶段核验

每次只复查修改影响的器件、网络和规则；阶段结束保留所需完整核验。导入/脚本返回成功后读回实际对象和网表，确认修改已应用。出现异常按实际错误修复或回退；不以重试次数代替结果。

## 最终检查

| 项目 | 证据与完成条件 |
|---|---|
| 原理图—PCB | 同一修订逐引脚网络与器件比较；差异已解释，不擅自改电气功能 |
| 连通与铺铜 | 所有预期连接闭合，无遗漏飞线；重铺后检查孤岛、细颈及热连接 |
| DRC | 当前原生工程实际执行的最终报告；非预期错误解决，例外逐项列出依据 |
| PCB-G06 | GND 过孔接入兼容地平面，无法布孔的位置与短线原因有记录 |
| PCB-G08 / PCB-L19 | 非GND连接后铺铜/缝合/DRC，再处理残余GND；用户已完成通道和敏感区与保护基线比较 |
| PCB-R07 | 独立检查同层中心线，非过孔 90° 转角为 0；采用 45°或相切圆弧；有ARC/CARC时检查真实弧长和全弧几何。只豁免真实过孔中心换层的投影方向变化，不为规避检查增孔 |
| PCB-R11 | 连续段线宽一致，电源/GND 的局部10 mil与恢复20 mil逐段有据；检查载流瓶颈 |
| PCB-L17 | MCU同层去耦、对应电源域、大小电容连接点顺序与短回地；例外说明 |
| 差分 | 实际端点、两线铜长/长度差、线宽/净距、阻抗计算输入与结果、逐段真实参考回流 |
| PCB-L18 | 每颗晶振分别检查布局、拓扑、过孔、逐层无关线避让及铜皮/护地 |
| PCB-P09 | 物理层用途、EDA原生层类型、实际平面分区与Gerber一致；明确内电层时核对原生类型，转换后重验 |
| 机械与丝印 | 板框/孔/锁定对象与基线一致；无重叠/装配冲突，LED与排针功能标记完整 |
| 制造输出 | 打开实际 Gerber/钻孔或约定生产格式，确认层序、板框、开槽、钻孔、阻焊与修订，按需核对 BOM/坐标/装配图 |

完整交付同时保留原生工程、规则配置、验证报告、制造输出和简短变更记录。离线候选或未导入路线不作为工程完成证据。

## 结论边界

文档门禁证明规则入口存在；DRC 证明其覆盖的规则；阻抗计算证明指定模型下的计算结果。它们都不能代替 SI/PI、载流/温升、起振、EMC 或实测。无法获取可靠网表、铜皮或工具时，标记无法验证的对象和范围。

状态使用“通过/失败/未检查/不适用”，后两者写理由。报告包含修订、时间、工具版本、证据文件和未关闭问题。Token/费用仅从可用用量记录统计；缺少记录就说明不能准确计量，不承诺固定节省比例。
