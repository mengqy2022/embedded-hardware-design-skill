# PCB-V07：布局与交付证据门槛

来源：2026-11-03用户复盘。既有PCB-V04、PCB-L01/L17/L20没有成为逐项验收条件，文档编号门禁和DRC不能检出这类执行遗漏。本条增加执行记录，不改变电路参数。

## 两个阶段

| 阶段 | 进入下一步前的条件 |
|---|---|
| layout，开始大规模布线前 | 机械基线一致；每个器件的焊盘/本体及焊接工具空间已审查（含同网、DNP及模块）；每个电源/稳压/偏置脚已有对应电容或准确资料支持的例外，预留同层供电和回地路径；晶振、差分/射频通道未被挤占。允许局部试布验证可行性 |
| final，完整交付前 | 对最终实际铜路重做装配及逐脚去耦检查；完成同修订网表/连通、GND、转角、线宽/载流、层类型、晶振/差分、丝印、DRC、泪滴→重铺→DRC和实际制造文件复核 |

不需要每步请求用户批准。未通过或缺证据时自行修正受影响区域；遇到锁定条件或授权冲突才说明冲突。适用项目清单须补充接口专用、隔离、RF等约束，本表不替代准确器件指南。

## 最小记录

复制[阶段记录模板](../assets/PCB_STAGE_REVIEW.json)，每阶段各存一份，填project/revision及stage。证据文件复用现有报告和局部图，不重新复制全文。

1. 从本轮原理图/PCB生成inventory.json：`{"components":["U1","C1"],"power_pins":["U1.4"]}`。器件清单包括机械和DNP对象（逐项说明装配状态），电源脚按准确芯片逐脚分类，含VIN/VOUT、模拟域、内部稳压/偏置及有意不用的电源脚。INVENTORY证据记录导出来源、分类方法及覆盖比较；脚名识别不能只靠网络名。无电源脚的无源板填no_power_pins_reason。不凭手写少量清单宣称全覆盖。
2. artifacts登记当前PCB源、inventory及已有核验文件的相对路径和SHA-256。每个checks条目及每个components/power_pins条目填status（pass或not_applicable）、evidence（artifacts中的核验文件键）、rationale（结论/适用边界）；不适用也要有核验依据。布局只要求布局阶段条目，最终要求全部条目。
3. 每个器件的证据注明相邻对象/最小实际间距、本体或庭院/工具接近方向、紧凑例外。不能仅用异网DRC或全板最小焊盘间距证明所有器件可焊；不得为了间距拉长敏感回路。
4. 每个电源脚的证据注明电容位号/容量/电源域及资料页码；layout记录计划的供电及回地，final记录实际焊盘到脚的铜路径、层/过孔和电容GND→有效地铜/过孔→IC地的完整路径。回地测不到时保留未检查，不能仅用最近GND过孔中心距替代完整回流核验。允许多脚共享电容，但每脚仍需有据；区分去耦、储能、晶振负载、VMID及RF匹配。
5. 从实时EDA新导出PCB源后运行：

```powershell
python scripts/check_pcb_stage.py <项目目录>/review/PCB_STAGE_FINAL.json --pcb <当前导出的PCB源.epcb> --stage final
```

布局阶段使用 `--stage layout`；交付阶段必须使用 `--stage final`，不能拿布局记录代替。门禁检查阶段条目、全器件/电源脚覆盖、证据文件存在及哈希、PCB路径/版本一致性。缺项、失败、无依据的不适用或文件变化均返回非零。输入来自人工/工具审查，脚本不判断报告内容是否正确、不自动运行DRC、不证明清单分类完整或硬件性能；阶段通过不能据此放行量产。

改动器件位置/层、封装、供电或地铜后，重审受影响对象并更新对应证据；未受影响记录可在有差异比较的条件下沿用，说明复用依据。最终门禁必须对应新导出的完整设计，不能只刷新哈希伪装完成复核，不能接受历史快照代替当前EDA。
